# best-sellers

Saatte bir Tebex'ten son 30 günün satışlarını okur, en çok satan 3 paketin id'sini `best.json`'a yazar. Mağaza teması bu dosyayı okur; satış sayısı yayımlanmaz.

Kurulum: Settings → Secrets and variables → Actions → `TEBEX_SECRET` (Tebex → Integrations → API Keys → Secret key). Elle çalıştırma: Actions → best-sellers → Run workflow.
